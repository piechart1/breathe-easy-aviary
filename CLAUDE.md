## Project status

`STATUS.md` at the repo root is this project's status sheet. Never hand-edit the
generated block between the `status:begin` and `status:end` markers.

After anything that changes the project's shape (a version bump, a new dependency,
a release, an Android prebuild), or when what is blocking the project or what comes
next has changed, use the `project-status` skill to update it.
